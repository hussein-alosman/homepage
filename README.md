# Hussein Al Osman — Academic Homepage

An original, responsive, static academic homepage built with HTML and CSS. No frameworks or build tools needed.

## Publish to GitHub Pages

1. Create a public GitHub repository called `YOUR-USERNAME.github.io` (or `homepage`).
2. Upload `index.html`, `style.css`, and `sources.html` to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
4. Visit `https://YOUR-USERNAME.github.io/` (or `https://YOUR-USERNAME.github.io/homepage/`).

## Edit

- Change the bio, publications, email, and links in `index.html`.
- Adjust typography, colors, and layout in `style.css`.
- Review the sources and accuracy disclaimer in `sources.html` before publication.

This is an independent draft, not an official University of Ottawa site. Verify all details and obtain approval before publishing it as someone's personal homepage.
